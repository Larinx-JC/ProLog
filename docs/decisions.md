## Change discipline

Record a change to a confirmed choice with the owner's decision and update the
affected acceptance criteria, tests, and documentation together. Deferrals must
name a responsible section and a testable outcome. Preserve prior review
context in [review history](review-history.md); use the
[outline](outline.md) for current scope.
